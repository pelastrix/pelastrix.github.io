Privacy Policy

Last updated: 11 October 2026

Obsidian Sync is a personal tool used only by its owner to sync their own notes between their own devices and their own Google Drive.

Data accessed

The app requests the drive.file permission, so it can only see and change files and folders it created itself in the signed-in user's Google Drive. It cannot access any other Drive files.

Data use and storage

  • Files move directly between the user's devices and Google Drive. No other server is involved.
  • No data is collected, stored, shared, sold or analysed by the developer.
  • Sign-in tokens are stored only on the user's own devices.

Google API Services

Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Removing access

Access can be revoked at any time at myaccount.google.com/permissions.
